# Telegram-бот: ученик и кухня

Один бот обслуживает две роли. Роль определяется по Telegram ID: если ID есть в `TELEGRAM_ADMIN_IDS`, человек считается
сотрудником кухни, иначе — учеником. Сайт при этом остаётся рабочим кабинетом кухни; ученик им не пользуется.

```
TELEGRAM_ADMIN_IDS=123456789,987654321
```

Список читается при старте процесса, поэтому после правки `.env` бота нужно перезапустить.

## Матрица доступа

| Действие | Ученик | Сотрудник кухни |
|---|---|---|
| Главное меню `/start` | да | да |
| Меню на учебный день | да, с выбором блюда | да, только просмотр |
| Заказать / изменить блюдо | да | нет |
| Отменить заказ | да, только свой | нет |
| Сводка `/summary` | нет | да |
| Ввод остатков `/leftover` | нет | да |
| История остатков | нет | да |
| Рассылка `/stop` | да | да |

Отказ всегда вежливый и возвращает клавиатуру своей роли, а не ошибку:

```
Ученик → «🔒 Сводка для кухни доступна только сотрудникам.»
Ученик → «🔒 Остатки вносят только сотрудники кухни.»
Ученик → «🔒 История остатков доступна только сотрудникам.»
Сотрудник → «Предзаказ доступен ученикам в этом Telegram-боте. Здесь — быстрые действия кухни.»
```

## Ученик

### `/start`

```
👋 Привет! Я бот предзаказа «Умной столовой».

🏠 Главное меню

✅ Ваш заказ на понедельник, 2 ноября: A — Каша без комков + котлета с пюре.

Выберите действие кнопкой ниже 👇

[🛒 Заказать обед]
[🧾 Мой заказ] [📋 Меню]
[❓ Помощь]
```

Если заказа нет, строка статуса меняется на «🛒 Заказ на … ещё не оформлен.». `/start` также подписывает на утреннюю
рассылку.

### `/order` или «Заказать обед»

```
🛒 Заказ на понедельник, 2 ноября

Выберите блюдо — это одно нажатие. Передумать можно до дня обеда.

[✅ A · Каша без комков…] [🍽️ B · Овощные котлеты с пюре 🌱]
[❌ Отменить заказ]
[🏠 Главное меню]
```

Текущий выбор отмечен ✅ и подписан названием блюда, вегетарианское помечено 🌱. Выбор блюда заменяет предыдущий заказ
без дополнительного подтверждения.

### После сохранения

```
✅ Заказ сохранён

📅 понедельник, 2 ноября
🍽️ Блюдо B — Овощные котлеты с пюре 🌱

Можно изменить выбор, пока не наступил день обеда.

[🔄 Изменить блюдо] [❌ Отменить заказ]
[🧾 Мой заказ] [📋 Меню]
[🏠 Главное меню]
```

Повторный выбор того же блюда ничего не ломает: бот отвечает «✅ Блюдо A уже выбрано на …».

### `/myorder`

```
✅ Ваш заказ

📅 понедельник, 2 ноября
🍽️ Блюдо A — Каша без комков + котлета с пюре

Можно изменить выбор или отменить заказ.

[🔄 Изменить блюдо] [❌ Отменить заказ]
[🏠 Главное меню]
```

Без заказа: «ℹ️ Заказ на … не оформлен.» и кнопка «🛒 Заказать обед».

### `/cancel`

- заказ есть → «❌ Заказ на … отменён.» и сразу клавиатура выбора;
- заказа нет → «ℹ️ Заказа на … не было.»;
- кнопка от прошлой даты → «ℹ️ Этот заказ уже неактуален.» и выбор на актуальный день. Исторический заказ не удаляется.

### `/stop`

«Рассылка отключена. Чтобы подписаться снова, отправьте /start.»

## Сотрудник кухни

### `/start`

```
👋 Привет! Я бот «Умной столовой» для сотрудников кухни.

🏠 Главное меню сотрудника

📅 Меню на понедельник, 2 ноября.
📊 Сегодня заказов: 12 (A — 7, B — 5).

Сводка, остатки и меню — кнопками ниже 👇

[📊 Сводка на сегодня] [📝 Внести остатки]
[📋 Меню] [📈 История остатков]
[❓ Помощь]
```

### `/summary` и `/summary 2026-11-02`

```
📊 Сводка для кухни
📅 понедельник, 2 ноября

🥗 Заказов A: 7
🍕 Заказов B: 5
🌱 Вегетарианских: 2
📋 Всего заказов: 12
⏳ Не ответили: 488 (из 500)
📦 Базовые порции: 12
🛡️ Резерв 5%: 1
✅ Итого порций: 13

[📝 Внести остатки] [📈 История остатков]
[🏠 Главное меню]
```

Если распределение A/B для не ответивших неизвестно, добавляется предупреждение — выдуманных чисел бот не показывает.
В выходной день сводка формируется, но помечается «ℹ️ В этот день столовая не работает.».

### `/leftover` — пошаговый ввод

```
📝 Внести остатки после обеда

Отправьте одной строкой:
1.5 2 примечание

• 1.5 — масса отходов в кг
• 2 — сколько порций осталось
• примечание необязательно

Запись добавится в историю. Отмена — кнопкой ниже.

[✖️ Отмена]
[🏠 Главное меню]
```

Следующее сообщение сотрудника сохраняется как запись. Одна строка `/leftover 1.5 2 примечание` работает без
режима ожидания. Запятая как десятичный разделитель принимается: `1,5 2`.

Успех:

```
✅ Остатки сохранены

♻️ Отходы: 1.5 кг
🍽️ Осталось порций: 2
📝 примечание
```

Ошибка ввода не выходит из режима, клавиатура отмены остаётся:

```
⚠️ Не получилось сохранить.

Нужны два неотрицательных числа: кг и целое число порций.
Пример: 1.5 2 примечание
```

Режим ввода завершается любой кнопкой, командой `/cancel` или другой командой — «✖️ Ввод остатков отменён.» /
«ℹ️ Нет активного действия.».

### История остатков

```
📈 Последние остатки

• понедельник, 2 ноября: 1.5 кг, 2 порции
  примечание
```

Пустое состояние: «Записей пока нет. После обеда внесите остатки кнопкой «📝 Внести остатки».». Показываются последние
пять записей.

### Меню

Меню сотруднику доступно только для просмотра: подпись «👀 Режим сотрудника: только просмотр.» и кнопки «📊 Сводка на
сегодня» / «🏠 Главное меню». Кнопок заказа нет.

## Команды

| Команда | Ученик | Сотрудник |
|---|---|---|
| `/start` | подписка + главное меню | главное меню кухни |
| `/menu` | меню с выбором блюда | меню без выбора |
| `/order` | выбор блюда | отказ |
| `/myorder` | свой заказ | отказ |
| `/cancel` | отмена заказа | выход из ввода остатков |
| `/stop` | отключить рассылку | отключить рассылку |
| `/summary [YYYY-MM-DD]` | отказ | сводка |
| `/leftover [кг порции примечание]` | отказ | ввод остатков |
| `/help` | помощь ученика | помощь кухни |

Меню команд в интерфейсе Telegram синхронизируется отдельно для каждой роли:

```bash
python bot.py commands
```

Вызывается и при старте `bot.py run`. Команда ставит ученический набор по умолчанию и персональный набор для каждого ID
из `TELEGRAM_ADMIN_IDS`.

Неизвестная команда: «🤔 Неизвестная команда /foo. Напишите /help.» Кнопка от прошлой версии: «ℹ️ Эта кнопка устарела.
Вот главное меню.»

## Кнопки и callback-данные

| Данные | Действие |
|---|---|
| `nav:home` | главное меню роли |
| `nav:menu` | меню на ближайший учебный день |
| `nav:order` | выбор блюда (ученик) |
| `nav:myorder` | свой заказ (ученик) |
| `nav:summary` | сводка (кухня) |
| `nav:leftover` | ввод остатков (кухня) |
| `nav:leftovers` | история остатков (кухня) |
| `nav:help` | помощь роли |
| `order:<дата>:<A\|B>` | сохранить заказ |
| `cancel:<дата>` | отменить заказ на дату |
| `leftover:cancel` | выйти из ввода остатков |

Callback всегда подтверждается через `answerCallbackQuery`, поэтому кнопка не «зависает» даже при отказе.

## Медиа

- Локальные изображения лежат в `assets/bot/` (11 файлов, ~1,1 МБ) и загружаются в Telegram через
  `multipart/form-data` — внешний CDN не нужен.
- Фото дня выбирается по дню недели: понедельник — каша, вторник — суп, среда — рыба с рисом, четверг — гуляш,
  пятница — пицца.
- Фото блюда выбирается по ключевым словам названия: суп, каша, пицца, макароны, рыба, рис, запеканка, яйца, салат,
  гречка, овощи, мясо.
- Если файла нет или `image_url` в меню указывает на HTTP-адрес, отправляется фото по URL.
- Если фото не отправилось, бот пишет предупреждение в лог и отправляет тот же текст без картинки.
- `CANTEEN_BOT_IMAGE_URL` переопределяет картинку главного экрана.

## Рассылка и планировщик

- Утренняя рассылка отправляет ученикам меню на ближайший учебный день с кнопками выбора, а сотрудникам — сводку на
  текущую дату.
- Если меню на день не опубликовано, вместо кнопок заказа приходит «меню ещё не опубликовано» и главное меню.
- `/stop` отключает рассылку до следующего `/start`.
- Планировщик помнит успешный запуск за дату в SQLite, поэтому перезапуск процесса не повторяет рассылку.

```bash
python bot.py broadcast   # разовая рассылка
python bot.py schedule    # планировщик, по умолчанию 09:00
python bot.py check       # getMe + число админов и подписчиков, без отправки сообщений
```

## Ограничения прототипа

- Заказ доступен только на ближайший учебный день.
- Ученик хранится под техническим кодом `TG-<chat_id>`; имя, класс и другие персональные данные не запрашиваются.
- Состояние ввода остатков хранится в памяти процесса: перезапуск бота его сбрасывает.
- Реальная рассылка требует токен Telegram; безопасная проверка — `python bot.py check`.
