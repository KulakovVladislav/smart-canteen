# Бот предзаказа: пример диалога и сводка

## Сценарий диалога

1. Бот: «Привет! На завтра есть два блюда: A и B (без мяса). Что выбираешь?» Две кнопки.
2. Ученик нажимает кнопку. Бот подтверждает выбор и напоминает, что его можно изменить до закрытия опроса.
3. Если ученик не ответил, его выбор не распределяется автоматически; сводка показывает не ответивших отдельно. Оценка
   по историческим долям доступна в веб-интерфейсе как ручной режим.
4. В 09:00 бот формирует сводку для повара.

## Пример диалога

```
Бот: Привет! На завтра есть два блюда:
     A — Куриный суп + макароны с двойной нормой сыра
     B — Овощной суп + макароны с сыром (без мяса)
     Что выбираешь?
Ученик: [нажимает B]
Бот: Принято: блюдо B. Можно изменить до 08:30.
```

## Формат сводки

Дата, число порций блюда A, число порций блюда B, число вегетарианских выборов, число не ответивших, запас на отклонение
(например, 5%), итоговое число порций к приготовлению.

Пример:

```
Дата: завтра
Порций блюда A: 5
Порций блюда B: 7
Вегетарианских выборов: 7
Не ответили: 3
Запас на отклонение (5%): 1
Итого порций к приготовлению: 13
```

Полноценный Telegram-бот на первом этапе не нужен: показываем пример диалога и сгенерированную по нему сводку.
