# Telegram-бот: ученик и кухня

Сайт предназначен только для кухни и управляющих. Ученик не входит на сайт: весь предзаказ происходит в Telegram.

## Ученик

1. Отправляет `/start` и подписывается на меню.
2. Нажимает «Заказать обед».
3. Выбирает вариант A или B на ближайший учебный день.
4. В любой момент до дня обеда открывает «Мой заказ», меняет выбор или отменяет его.

```
Бот: Меню на вторник, 3 ноября
     A — Куриный суп + макароны с двойной нормой сыра
     B — Овощной суп + макароны с сыром 🌱
     [Выбрать A] [Выбрать B]

Ученик: [Выбрать B]
Бот: Заказ сохранён. Вторник, 3 ноября — блюдо B.
     [Мой заказ] [Меню]
```

Каждый пользователь хранится под техническим кодом `TG-<chat_id>`; имени, класса и других персональных данных бот не
запрашивает.

## Сотрудник кухни

Telegram ID сотрудника указывается в `TELEGRAM_ADMIN_IDS`. После `/start` ему доступны только быстрые действия кухни:

- сводка по заказам A/B, вегетарианским выборам, резерву и количеству не ответивших;
- ввод остатков одной строкой: `1.5 2 примечание`;
- последние измерения остатков;
- просмотр меню без возможности оформить ученический заказ.

## Рассылка

Утренняя процедура отправляет ученикам меню на ближайший учебный день с кнопками выбора, а сотрудникам — сводку на
текущую дату. Команда `/stop` прекращает получение рассылки до следующего `/start`.

## Ограничения прототипа

- Заказ доступен только на ближайший учебный день.
- При отсутствии ответа кухня видит это отдельно и не получает выдуманное распределение A/B.
- Реальная рассылка требует токен Telegram и проверяется командой `python bot.py check` без отправки сообщений.
