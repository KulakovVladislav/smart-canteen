# План реализации «Умной столовой»

## Текущее состояние

- Базовый прототип реализован: меню, предзаказ, сводка кухни, остатки, экономика, проверка бюджета.
- CLI и Streamlit-интерфейс работают.
- Тесты: `python3 -m unittest` (74 теста).
- Smoke: `python3 app.py all`, `streamlit run web_app.py`.

## Выполненные улучшения

- Усилена валидация меню: обязательное вегетарианское блюдо, непустой `complaint_cluster`, булевы флаги.
- Упрощён и нормализован разбор стоимостей `_extract_costs` с поддержкой `dict`, `list`, `tuple`.
- Добавлены smoke-тесты CLI и тесты форматов стоимостей/валидации.
- Улучшена обработка HTTP в `ai_menu.py` (retry/backoff).
- Сценарии экономии ограничены снизу нулём; константы вынесены в переменные окружения.
- Добавлена адаптивность CSS и обновлена документация.

## Следующие шаги

- Полноценная авторизация и защита данных для публичного развёртывания.
- Тесты интерфейса и сетевого слоя.
- Конфигурация БД/экономических констант через файл.
