# План развития «Умной столовой»

## Завершено в прототипе

- Telegram-предзаказ для ученика: A/B, просмотр, изменение, отмена и утренняя рассылка.
- Быстрые действия кухни в Telegram: сводка, остатки, история.
- Раздельные разделы сайта для кухни и управления без ученических страниц.
- Единый демонстрационный набор SQLite для презентации.
- Светлая и тёмная темы, адаптивная сетка показателей кухни.
- Фактические остатки сопоставляются с ориентиром массы отходов; экономические цифры честно помечены как модель.

## Перед внешним развёртыванием

1. Заменить общий код доступа сайта на полноценную авторизацию сотрудников и журнал действий.
2. Настроить HTTPS, резервное копирование SQLite и мониторинг процесса бота.
3. Утвердить правила хранения технических Telegram ID и срок их удаления.
4. Подключить финансовую первичку, если требуется рассчитывать подтверждённую, а не модельную экономию.
5. Проверить бота в отдельном тестовом чате перед первой массовой рассылкой.
