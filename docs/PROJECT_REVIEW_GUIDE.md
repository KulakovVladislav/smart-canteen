# Smart Canteen — состояние прототипа

## Для кого

- **Ученики** используют только Telegram-бот для выбора блюда A/B.
- **Кухня** использует Telegram для быстрых действий и сайт для расширенной сводки и учёта остатков.
- **Управляющие** используют сайт для меню, себестоимости, экономики и AI-предложений.

## Подтверждённый сценарий

1. Управляющий публикует меню из пяти учебных дней.
2. Ученик в Telegram выбирает, меняет или отменяет блюдо на ближайший учебный день.
3. Заказы сохраняются в SQLite; кухня видит A/B, вегетарианские варианты, резерв и неответивших.
4. После обеда кухня вносит массу отходов и остатки порций.
5. Управляющий сравнивает фактическую массу отходов с ориентиром кейса и отдельно смотрит модельные денежные сценарии.

## Что проверяется перед показом

```bash
.venv/bin/python -m unittest
.venv/bin/python app.py demo
.venv/bin/python app.py all
.venv/bin/python bot.py check
```

`bot.py check` вызывает только Telegram `getMe`; рассылка и AI-генерация не запускаются этой командой.

## Честные ограничения

- Денежная экономия — модель по данным кейса, а не подтверждённый финансовый результат.
- Роли на сайте — навигация. Для внешнего доступа нужно задать `CANTEEN_WEB_ACCESS_CODE`, использовать HTTPS и добавить
полноценную корпоративную авторизацию.
- AI-предложение сохраняется только после проверки структуры и явного действия управляющего.
- Планировщик фиксирует успешную рассылку за дату в SQLite; реальная эксплуатация всё равно требует мониторинга и
резервного копирования базы.
