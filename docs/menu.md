# Меню на 5 дней: жалобы → решения

## Соответствие жалоб и действий в меню

| Жалоба (доля)                                      | Что делаем в меню                                                                                     |
|----------------------------------------------------|-------------------------------------------------------------------------------------------------------|
| Рыба холодная, с костями, рис сухой (45%)          | Рыбные наггетсы без костей, запечённые; подача горячей порцией; рис рассыпчатый, с овощами или соусом |
| В каше комки, порция большая (25%)                 | Каша без комков, порция меньше, добавка по желанию                                                    |
| В макаронах мало сыра (15%)                        | Увеличить норму сыра, проверить влияние на себестоимость                                              |
| Вегетарианцам нечего есть (10%)                    | В каждый день одно блюдо без мяса                                                                     |
| Не успевают из-за очереди и короткой перемены (5%) | Предзаказ: порции готовятся и выдаются по заказам, отдельная быстрая выдача                           |

## Меню на 5 дней

| День        | Блюдо A                                         | Блюдо B (без мяса)                                           | Какую жалобу закрывает                        |
|-------------|-------------------------------------------------|--------------------------------------------------------------|-----------------------------------------------|
| Понедельник | Каша без комков (малая порция) + котлета с пюре | Овощные котлеты с пюре                                       | В каше комки, порция большая                  |
| Вторник     | Куриный суп + макароны с двойной нормой сыра    | Овощной суп + макароны с сыром                               | В макаронах мало сыра                         |
| Среда       | Рыбные наггетсы без костей + рис с овощами      | Овощные биточки + рис с овощами                              | Рыба холодная, с костями, рис сухой           |
| Четверг     | Гороховый суп + гуляш с гречкой                 | Гороховый суп на овощном бульоне + гречка с тушёными овощами | Вегетарианцам нечего есть                     |
| Пятница     | Запеканка творожная                             | Школьная пицца без мяса                                      | Не успевают из-за очереди и короткой перемены |

Пятницу почти не трогаем: там выбрасывается всего 8%, и это эталон того, что работает.

## Проверка по бюджету

Потолок себестоимости: 140 сом на порцию (140 × 500 = 70 000 сом, дневной бюджет). Конкретные цены продуктов в
источниках отсутствуют, поэтому все стоимости помечаются как допущения для проверки («не указано»). Бюджет-валидатор
принимает переданные себестоимости и проверяет, что каждая ≤ 140 сом; неизвестные помечаются «не указано».
