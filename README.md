# Умная столовая

«Умная столовая» — демонстрационный прототип для школьной столовой. Ученики выбирают блюдо только в Telegram-боте;
сайт — рабочий кабинет кухни и управляющих с меню, сводкой, остатками, экономикой и контролем себестоимости.

## Основные функции

- Меню на 5 учебных дней, по 2 блюда на день, вегетарианский вариант.
- Предзаказ ученика в Telegram: выбор A/B, просмотр, изменение и отмена; данные сохраняются в SQLite.
- Сводка для повара: порции A/B, вегетарианские, не ответившие, резерв 5%, итого.
- Ручной ввод фактических остатков и история измерений.
- Экономические расчёты потерь и сценариев снижения отходов.
- Проверка себестоимости с явным статусом при неизвестных ценах.
- Необязательная генерация меню через внешнюю языковую модель.
- Сайт только для управляющих и кухни; Telegram разделяет сценарии ученика и сотрудника кухни.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Настройки удобно держать в `.env` (файл исключён из Git):

```bash
cp .env.example .env
```

## Запуск

Если системный Python не содержит установленных зависимостей, используйте интерпретатор виртуального окружения:
`.venv/bin/python` и `.venv/bin/streamlit`.

Веб-приложение:

```bash
streamlit run web_app.py
```

Интерфейс откроется по адресу `http://127.0.0.1:8501` (также доступен как `http://localhost:8501`). Сервер слушает
только локальный интерфейс и недоступен из локальной сети.

Командная строка:

```bash
python app.py all
python app.py menu
python app.py preorder
python app.py budget-check
python app.py demo                             # заменить локальные демо-данные единым набором для презентации
```

Тесты:

```bash
python -m unittest
```

## Настройка ИИ (необязательно)

Задайте переменные окружения:

```bash
export AI_API_KEY=...
export AI_BASE_URL=https://api.openai.com/v1   # необязательно
export AI_MODEL=gpt-4o-mini                    # необязательно
```

Если ключ не задан, приложение работает на сохранённом или встроенном меню и честно сообщает, что ИИ недоступен.

## Telegram-бот: ученики и кухня

```bash
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_ADMIN_IDS=123456789            # через запятую
export CANTEEN_EXPECTED_DINERS=500            # необязательно
python bot.py                                  # polling
python bot.py broadcast                        # разовая утренняя рассылка (меню + сводка)
python bot.py schedule                         # планировщик (по умолчанию в 09:00)
python bot.py check                            # безопасно проверить подключение (getMe)
python bot.py commands                         # синхронизировать меню команд по ролям
```

Роль определяется по Telegram ID: ID из `TELEGRAM_ADMIN_IDS` — сотрудник кухни, остальные — ученики.

| Возможность | Ученик | Кухня |
|---|---|---|
| Меню на учебный день | с выбором блюда | только просмотр |
| Заказ, изменение, отмена | да | нет |
| Сводка `/summary` | нет | да |
| Остатки `/leftover`, история | нет | да |
| Утренняя рассылка | меню с кнопками | сводка на сегодня |

Попытка чужого действия не ломает сценарий: бот отвечает пояснением и возвращает клавиатуру своей роли.

Команды ученика: `/start`, `/menu`, `/order`, `/myorder`, `/cancel`, `/stop`, `/help`.
Команды кухни: `/start`, `/summary [YYYY-MM-DD]`, `/leftover [кг порции примечание]`, `/menu`, `/help`.

Кнопки Telegram-меню команд синхронизируются командой `bot.py commands` (она же вызывается при старте `bot.py run`):
ученический набор ставится по умолчанию, кухонный — персонально для каждого ID из `TELEGRAM_ADMIN_IDS`. После правки
`.env` перезапустите бота.

Подробные сценарии, тексты и состояния кнопок: `docs/bot_dialog.md`.

### Фото в боте

Изображения лежат в `assets/bot/` и загружаются в Telegram напрямую через `multipart/form-data`, без внешнего CDN.
Фото дня выбирается по дню недели, фото блюда — по ключевым словам названия (суп, каша, пицца, макароны, рыба, рис,
запеканка, яйца, салат, гречка, овощи, мясо). Если файла нет или отправка не удалась, бот присылает тот же текст без
картинки. Переменная `CANTEEN_BOT_IMAGE_URL` переопределяет картинку главного экрана.

### Рассылка

Утреннее сообщение отправляет ученикам меню с кнопками выбора, а сотрудникам — сводку на текущую дату. `/stop`
отключает рассылку до следующего `/start`. Планировщик помнит успешный запуск за дату в SQLite, поэтому перезапуск
процесса не повторяет рассылку.

### Переменные окружения

Шаблон — `.env.example`. Файл `.env` читает `bot.py`; Streamlit и CLI берут значения из окружения процесса.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather | — |
| `TELEGRAM_ADMIN_IDS` | ID сотрудников кухни через запятую | пусто |
| `CANTEEN_EXPECTED_DINERS` | ожидаемое число питающихся для сводки | `500` |
| `CANTEEN_BOT_IMAGE_URL` | внешнее фото главного экрана бота | локальный `welcome.jpg` |
| `CANTEEN_BROADCAST_HOUR` / `CANTEEN_BROADCAST_MINUTE` | время планировщика | `9` / `0` |
| `CANTEEN_WEB_ACCESS_CODE` | код входа на сайт | без кода, только локально |
| `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL`, `AI_PROVIDER` | необязательная генерация меню | — |

## Архитектура

Канонические модули:

- `domain/menu.py`, `domain/preorder.py`, `domain/economics.py`, `domain/waste_calc.py` — предметная логика.
- `repositories/storage.py`, `repositories/database.py` — SQLite: заказы, стоимости, остатки, меню.
- `services/ai_menu.py` — необязательная генерация меню через OpenAI-совместимый API.
- `services/telegram_bot.py` — Telegram-бот: предзаказы учеников и быстрые действия кухни в одном защищённом по ролям интерфейсе.
- `ui/streamlit/main.py` — Streamlit-интерфейс и стили.
- `app.py` — CLI, `web_app.py` — точка входа веб-приложения.

Совместимость: `src/*` — тонкие обёртки-алиасы над каноническими модулями. Отдельные устаревшие имена функций в
канонических модулях могут выдавать `DeprecationWarning`.

## Ограничения безопасности

- Локальный демонстрационный прототип: нет полноценных учётных записей, паролей и журнала доступа.
- Веб-приложение предназначено только для управляющих и кухни. При заданном `CANTEEN_WEB_ACCESS_CODE` оно запрашивает
код перед входом; без него работает в локальном демонстрационном режиме. При доступе из локальной сети включайте код
обязательно.
- В Telegram роль определяется по ID из `TELEGRAM_ADMIN_IDS`: действия кухни недоступны остальным пользователям, а
ученик может изменить или отменить только свой заказ. Бот хранит технический chat ID `TG-<id>` и не запрашивает имя,
класс и другие персональные данные. `/stop` отключает рассылку.
- Токен бота и список администраторов храните в `.env` (файл исключён из Git) и не публикуйте.
- Не публикуйте приложение без проверки безопасности.
- Перед реальным развёртыванием необходимо закрыть: аутентификацию, защиту данных, HTTPS, резервное копирование БД,
  аудит доступа, проверку развёртывания.
