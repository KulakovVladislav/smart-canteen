# Умная столовая

«Умная столовая» — демонстрационный прототип для школьной столовой. Ученики выбирают блюдо только в Telegram-боте;
сайт — рабочий кабинет кухни и управляющих с меню, сводкой, остатками, экономикой и контролем себестоимости.

## Основные функции

- Меню на 5 учебных дней, по 2 блюда на день, вегетарианский вариант.
- Предзаказ ученика в Telegram: выбор A/B, просмотр, изменение и отмена; данные сохраняются в SQLite.
- Сводка для повара: порции A/B, вегетарианские, не ответившие, резерв 5%, итого.
- Ручной ввод фактических остатков и история измерений.
- Экономические расчёты потерь и сценариев снижения отходов.
- Проверка себестоимости с явным статусом при неизвестных ценах.
- Необязательная генерация меню через внешнюю языковую модель.
- Сайт только для управляющих и кухни; Telegram разделяет сценарии ученика и сотрудника кухни.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Если системный Python не содержит установленных зависимостей, используйте интерпретатор виртуального окружения:
`.venv/bin/python` и `.venv/bin/streamlit`.

Веб-приложение:

```bash
streamlit run web_app.py
```

Интерфейс откроется по адресу `http://127.0.0.1:8501` (также доступен как `http://localhost:8501`). Сервер слушает
только локальный интерфейс и недоступен из локальной сети.

Командная строка:

```bash
python app.py all
python app.py menu
python app.py preorder
python app.py budget-check
python app.py demo                             # заменить локальные демо-данные единым набором для презентации
```

Тесты:

```bash
python -m unittest
```

## База данных

## Настройка ИИ (необязательно)

Задайте переменные окружения:

```bash
export AI_API_KEY=...
export AI_BASE_URL=https://api.openai.com/v1   # необязательно
export AI_MODEL=gpt-4o-mini                    # необязательно
```

Если ключ не задан, приложение работает на сохранённом или встроенном меню и честно сообщает, что ИИ недоступен.

## Telegram-бот: ученики и кухня

```bash
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_ADMIN_IDS=123456789            # через запятую
export CANTEEN_EXPECTED_DINERS=500            # необязательно
python bot.py                                  # polling
python bot.py broadcast                        # разовая утренняя рассылка (меню + сводка)
python bot.py schedule                         # планировщик (по умолчанию в 09:00)
python bot.py check                            # безопасно проверить подключение (getMe)
```

Ученики используют `/start`, `/menu`, `/order`, `/myorder`, `/cancel`. Сотрудники, чьи ID перечислены в
`TELEGRAM_ADMIN_IDS`, получают отдельное меню: сводку, ввод остатков и историю. Утреннее сообщение отправляет
ученикам меню с кнопками выбора, а сотрудникам — сводку. Планировщик помнит успешный запуск за дату в SQLite, поэтому
перезапуск процесса не должен повторить рассылку.

## Архитектура

Канонические модули:

- `domain/menu.py`, `domain/preorder.py`, `domain/economics.py`, `domain/waste_calc.py` — предметная логика.
- `repositories/storage.py`, `repositories/database.py` — SQLite: заказы, стоимости, остатки, меню.
- `services/ai_menu.py` — необязательная генерация меню через OpenAI-совместимый API.
- `services/telegram_bot.py` — Telegram-бот: предзаказы учеников и быстрые действия кухни в одном защищённом по ролям интерфейсе.
- `ui/streamlit/main.py` — Streamlit-интерфейс и стили.
- `app.py` — CLI, `web_app.py` — точка входа веб-приложения.

Совместимость: `src/*` — тонкие обёртки-алиасы над каноническими модулями. Отдельные устаревшие имена функций в
канонических модулях могут выдавать `DeprecationWarning`.

## Ограничения безопасности

- Локальный демонстрационный прототип, без полноценной аутентификации и разграничения прав.
- Интерфейс не содержит реальной авторизации и ролевого разграничения доступа.
- Веб-приложение предназначено только для управляющих и кухни. При заданном `CANTEEN_WEB_ACCESS_CODE` оно запрашивает
код перед входом; без него работает в локальном демонстрационном режиме. Telegram хранит только технический chat ID для
доставки сообщений; действия кухни доступны лишь пользователям из `TELEGRAM_ADMIN_IDS`; `/stop` отключает рассылку.
- Не публикуйте приложение без проверки безопасности.
- Перед реальным развёртыванием необходимо закрыть: аутентификацию, защиту данных, HTTPS, резервное копирование БД,
  аудит доступа, проверку развёртывания.
